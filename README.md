# Myra: a family trip planner inside MakeMyTrip

Interactive prototype for the Razorpay Design x NID assignment. Persona: the Family Trip Planner (Mom plans; Dad, two kids and two grandparents travel).

- **Live prototype:** https://bhash-ray.github.io/myra-family-trip-planner/
- **Presentation (PDF):** https://bhash-ray.github.io/myra-family-trip-planner/Myra-presentation.pdf

Open the live link on a desktop browser. It shows a phone frame. A navy "NEXT" tag beside the phone shows what to tap on each screen (turn it off with the "Guide" button at the top right).

What to try: one question per screen, click a photo or upload IDs for travellers, a recommended budget, places and activities with reviews, a WhatsApp-style family vote, day-by-day trip mode with an SOS speed dial, and a five-star trip review.

Prices are estimates, not quotes. Place and travel photos are AI-generated for this prototype. Destination cover photos are from Unsplash photographers; full credits to be added.

Built by Bhaswati Gogoi, M.Des Game Design, NID Bangalore.
